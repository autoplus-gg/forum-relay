# Support

Forum Relay is community-maintained, self-hosted software. AutoPlus.gg does not operate a public bot or GitHub App and
cannot access or repair an operator's deployment.

For setup questions, reproducible bugs, and feature requests:

1. Check the setup, configuration, and operations documentation.
2. Search the repository's existing issues.
3. Open an issue with the Forum Relay version, Bun version, deployment method, relevant sanitized logs, and reproduction
   steps.

Never include tokens, private keys, webhook secrets, webhook URLs containing credentials, database files, private Discord
content, or private GitHub content. Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not the public issue
tracker.

Only the latest published release is supported. Best-effort community support does not include guaranteed response times.
